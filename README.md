# Quest Constructor
Frolov Alexander 231-322

Веб-конструктор интерактивных текстовых квестов. Серверная часть написана на
C# и ASP.NET Core, интерфейс — на HTML, CSS и JavaScript.

## Возможности

- создание, редактирование и удаление квестов;
- редактор сцен и переходов между ними;
- выбор стартовой сцены и создание нескольких концовок;
- условия перехода по предметам;
- получение и расходование предметов;
- изменение здоровья игрока;
- автоматическая проверка структуры квеста;
- поиск недостижимых сцен и неправильных переходов;
- режим прохождения прямо в браузере;
- статистика запусков и завершений;
- хранение проектов в JSON.

При первом запуске создаются пять демонстрационных квестов разных жанров.
Они показывают работу ветвлений, предметов, здоровья и нескольких концовок.

## Запуск на macOS

Требуется [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0).

```bash
cd ~/Desktop/QuestConstructor
dotnet run
```

После запуска откройте:

```text
http://localhost:5186
```

Остановка сервера: `Control + C`.

## Структура

```text
QuestConstructor/
├── Contracts/          # Объекты запросов и ответов API
├── Models/             # Квест, сцены, варианты выбора, игровая сессия
├── Services/           # Хранилище, валидация и игровая логика
├── wwwroot/            # HTML, CSS и JavaScript
├── Data/               # Локальная база квестов в формате JSON
└── Program.cs          # Настройка приложения и маршрутов API
```

Файл `Data/quests.json` создаётся автоматически при первом запуске и не
добавляется в Git. Если файла нет, приложение создаёт демонстрационный квест.

## Основные API-маршруты

| Метод | Адрес | Назначение |
| --- | --- | --- |
| `GET` | `/api/quests` | Получить все квесты |
| `POST` | `/api/quests` | Создать квест |
| `PUT` | `/api/quests/{id}` | Обновить квест |
| `DELETE` | `/api/quests/{id}` | Удалить квест |
| `POST` | `/api/quests/{id}/validate` | Проверить структуру |
| `POST` | `/api/games/start` | Начать прохождение |
| `POST` | `/api/games/{sessionId}/choices/{choiceId}` | Сделать выбор |
