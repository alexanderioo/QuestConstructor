# Как устроен проект

Этот файл помогает быстро понять код перед защитой проекта.

## 1. Запуск приложения

Выполнение начинается в `Program.cs`:

1. создаётся ASP.NET Core приложение;
2. регистрируются сервисы;
3. создаётся JSON-хранилище;
4. подключаются файлы из `wwwroot`;
5. описываются API-маршруты;
6. запускается веб-сервер.

## 2. Модель квеста

`Models/Quest.cs` содержит три связанных класса:

- `Quest` — весь проект пользователя;
- `QuestScene` — отдельный фрагмент истории;
- `QuestChoice` — действие игрока и переход к следующей сцене.

У перехода могут быть дополнительные правила:

- `RequiredItem` — предмет, без которого действие недоступно;
- `GrantedItem` — предмет, который получит игрок;
- `ConsumesRequiredItem` — нужно ли удалить использованный предмет;
- `HealthChange` — изменение здоровья от `-100` до `100`.

## 3. Граф сцен

Квест представляет собой ориентированный граф:

- сцена — вершина графа;
- вариант выбора — ребро;
- `NextSceneId` указывает, куда ведёт ребро;
- `StartSceneId` задаёт начальную вершину.

`Services/QuestValidator.cs` использует поиск в ширину (BFS), чтобы найти все
сцены, достижимые из начала. Так приложение обнаруживает изолированные сцены и
проверяет, существует ли путь к концовке.

## 4. Хранение данных

`Services/QuestRepository.cs` читает и записывает `Data/quests.json`.
`SemaphoreSlim` не позволяет двум запросам одновременно изменять файл.
Сначала данные записываются во временный файл, затем он заменяет основной.

## 5. Игровая логика

`Services/GameService.cs`:

1. создаёт игровую сессию;
2. хранит здоровье и инвентарь;
3. проверяет наличие требуемого предмета;
4. применяет результат выбора;
5. переводит игрока в следующую сцену;
6. определяет завершение квеста.

Сами квесты сохраняются между запусками программы, а игровые сессии хранятся
в оперативной памяти и очищаются после остановки сервера.

## 6. Frontend

- `wwwroot/index.html` — разметка экранов;
- `wwwroot/css/styles.css` — внешний вид и адаптивная вёрстка;
- `wwwroot/js/app.js` — состояние интерфейса и запросы к C# API.

Функция `api()` отправляет HTTP-запросы серверу. После ответа JavaScript
обновляет только нужную часть страницы без полной перезагрузки.

## 7. Что показать на защите

1. Создать квест.
2. Добавить обычную и финальную сцены.
3. Соединить их переходом.
4. Создать переход, требующий предмет.
5. Запустить проверку структуры.
6. Исправить специально созданную ошибку.
7. Пройти квест и показать инвентарь.
8. Перезапустить приложение и показать, что проект сохранился.
